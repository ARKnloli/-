## 关键决策

- **放弃 Electron**：在 Windows 上存在已知 Bug（`require('electron')` 返回字符串而非 API 对象），所有变通方案无效
- **选用 PyQt6**：系统托盘、剪贴板、SQLite 全部内置支持，打包为单文件 exe
- **图片保存**：PNG 格式存 images/ 目录，数据库记录路径
- **开机自启**：通过 Windows 注册表 Run 键实现
