## 详细连接表

### 1. 电源连接

```
┌─────────────────────────────────────────────────────────────────┐
│                         电源系统连接                             │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   ┌─────────┐        ┌─────────┐        ┌─────────┐            │
│   │ 6节电池 │───────→│ L298N   │───────→│ STM32   │            │
│   │ 9V      │   12V  │ 模块1   │   5V   │ 5V引脚  │            │
│   └────┬────┘        └────┬────┘        └────┬────┘            │
│        │                  │                  │                  │
│        └──────────────────┴──────────────────┘                  │
│                         共地（GND）                             │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

电源分配：
• 电池+ → L298N模块1的12V → L298N模块2的12V
• 电池- → L298N模块1的GND → L298N模块2的GND → STM32 GND
• L298N模块1的5V → STM32 5V（跳线帽在）
• STM32 3.3V → 蓝牙VCC → OLED VCC → 蜂鸣器VCC
```

## 总结

**系统硬件连接要点：**

1. **电源系统**：9V电池 → L298N(12V) → STM32(5V) → 3.3V模块
2. **共地设计**：所有模块GND必须连接在一起
3. **蓝牙通信**：USART，TX/RX交叉连接
4. **电机驱动**：双通道，ENA/IN1/IN2控制通道A，ENB/IN3/IN4控制通道B
5. **OLED显示**：I2C通信，只需2根线
6. **蜂鸣器**：GPIO推挽输出，低电平触发
