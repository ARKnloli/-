## 技术要点

### 字库格式
- 每个汉字32字节（16行×2字节/行）
- 每行2字节，先高字节后低字节（大端序）
- 取模方式：阴码，逐行式，顺向

### 显示函数
```c
// 显示单个汉字
void OLED_ShowChinese(uint8_t x, uint8_t y, Chinese_Char_Index index);

// 显示汉字字符串
void OLED_ShowChineseString(uint8_t x, uint8_t y, const Chinese_Char_Index *str, uint8_t len);
```

### 显示布局
```
┌────────────────────────┐
│ 智 能 小 车            │  ← 第0行：标题（16x16字体）
│ 状 态 ：停 止          │  ← 第2行：状态（16x16字体）
│ 速 度 ：1 0 0 %        │  ← 第4行：速度（6x8字体）
│ 接 收 ： 0             │  ← 第6行：接收（6x8字体）
└────────────────────────┘
```

## 问题记录

### 问题1：字库数据格式不正确
- **现象**：中文显示乱码
- **原因**：字库数据格式与OLED驱动不匹配
- **解决**：使用正确的取模软件生成字库

### 问题2：取模软件选择
- **推荐**：PCtoLCD2002
- **替代**：字模提取器、ZIMO
- **设置**：阴码，逐行式，顺向，16×16
