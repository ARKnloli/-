# 系统架构设计

## 1. 整体架构

```
┌─────────────────────────────────────────────────────────────┐
│                       应用层 (App)                           │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │  蓝牙遥控   │  │  状态显示   │  │  蜂鸣器提示  │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
├─────────────────────────────────────────────────────────────┤
│                       模块层 (Modules)                       │
│  ┌─────────────┐  ┌─────────────┐  ┌─────────────┐        │
│  │  电机控制   │  │  OLED显示   │  │  蓝牙通信   │        │
│  └─────────────┘  └─────────────┘  └─────────────┘        │
├─────────────────────────────────────────────────────────────┤
│                       驱动层 (Drivers)                       │
│  ┌─────────┐  ┌─────────┐  ┌─────────┐  ┌─────────┐      │
│  │  GPIO   │  │  UART   │  │  I2C    │  │  TIM    │      │
│  └─────────┘  └─────────┘  └─────────┘  └─────────┘      │
├─────────────────────────────────────────────────────────────┤
│                       硬件层 (Hardware)                      │
│  STM32F103C8T6 + 外设模块                                   │
└─────────────────────────────────────────────────────────────┘
```

## 2. 目录结构

```
stmf132/
├── src/                        # 源代码
│   ├── core/                   # 核心代码
│   │   ├── main.c              # 主程序入口
│   │   ├── system_init.c       # 系统初始化
│   │   └── interrupt.c         # 中断处理
│   ├── drivers/                # 硬件驱动
│   │   ├── gpio_driver.c       # GPIO驱动
│   │   ├── uart_driver.c       # UART驱动
│   │   ├── i2c_driver.c        # I2C驱动
│   │   └── tim_driver.c        # 定时器驱动
│   ├── modules/                # 功能模块
│   │   ├── motor_control.c     # 电机控制模块
│   │   ├── oled_display.c      # OLED显示模块
│   │   ├── bluetooth.c         # 蓝牙通信模块
│   │   └── buzzer.c            # 蜂鸣器模块
│   └── app/                    # 应用层
│       ├── remote_control.c    # 遥控应用
│       └── status_monitor.c    # 状态监控
├── inc/                        # 头文件
│   ├── drivers/
│   ├── modules/
│   └── app/
├── config/                     # 配置文件
│   ├── pin_config.h            # 引脚配置
│   └── project_config.h        # 项目配置
├── docs/                       # 文档
├── devlog/                     # 开发日志
└── tools/                      # 工具脚本
```

## 3. 模块依赖关系

```
app/remote_control.c
    ├── modules/bluetooth.c
    │   └── drivers/uart_driver.c
    └── modules/motor_control.c
        └── drivers/gpio_driver.c

app/status_monitor.c
    ├── modules/oled_display.c
    │   └── drivers/i2c_driver.c
    └── modules/buzzer.c
        └── drivers/gpio_driver.c
```

## 4. 中断分配

| 中断 | 用途 | 优先级 |
|------|------|--------|
| USART1 | 蓝牙数据接收 | 高 |
| TIM2 | 电机PWM控制 | 中 |
| TIM3 | 系统定时 | 低 |
| EXTI0 | 外部触发（预留） | 低 |

## 5. 内存规划

| 区域 | 大小 | 用途 |
|------|------|------|
| Flash | 64KB | 程序存储 |
| SRAM | 20KB | 运行时数据 |
| Stack | 1KB | 函数调用栈 |
| Heap | 512B | 动态分配（尽量避免） |
