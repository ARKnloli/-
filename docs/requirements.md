# 产品需求文档 — 历史粘贴板

## 概述

一款 Windows 桌面粘贴板管理工具，自动记录用户复制（Ctrl+C）的文字和图片，方便随时查找和历史复用。

## 功能需求

### F1. 剪贴板监听
- 自动监听系统剪贴板变化
- 支持**文字**和**图片**两种内容类型
- 内容去重：相同内容不重复保存
- 监听间隔：500ms

### F2. 历史记录查看
- 点击系统托盘图标打开主窗口
- 以**卡片列表**形式展示所有历史记录
- 排序规则：**置顶优先**，同等置顶状态下按**时间降序**（最新在上）
- 文字卡片：显示前 30 字的预览
- 图片卡片：显示缩略图

### F3. 卡片操作
- **复制**：点击卡片将内容重新写入剪贴板，可供粘贴使用
- **置顶/取消置顶**：将常用记录固定在列表顶部
- **删除**：移除单条记录

### F4. 搜索
- 顶部搜索框，输入关键词实时过滤
- 仅搜索文字内容，不搜索图片

### F5. 存储期限
- 用户可在设置中选择：**1 天 / 3 天 / 5 天**
- 默认：3 天
- 超过期限的非置顶记录自动删除

### F6. 图片容量管理
- 图片总大小上限：**500MB**
- 超过上限时，从最旧的图片开始自动删除（含置顶图片）
- 设置面板显示当前图片用量和进度条

### F7. 系统托盘
- 应用启动后常驻系统托盘（任务栏右下角）
- 托盘图标右键菜单：打开主界面 / 退出
- 关闭主窗口时**不退出程序**，仅隐藏到托盘

### F8. 开机自启
- 安装后默认开启自启（可关闭）
- 开机后自动最小化到托盘

## 非功能需求

### N1. 数据隐私
- 所有数据仅存储在用户本地电脑
- 不进行任何网络通信

### N2. 性能
- 历史记录数量在 10000 条以内时，主窗口打开和搜索响应时间 < 500ms
- 图片文件存储到磁盘，不在数据库中存 blob

### N3. 界面
- 中文界面
- 简洁直观风格，淡蓝色主色调
- 窗口默认大小：400×600 像素

### N4. 兼容性
- Windows 10 / Windows 11
