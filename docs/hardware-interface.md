## 电源连接

### 4节干电池 → L298N
```
电池+ (6V) → L298N 12V输入
电池- (GND) → L298N GND
```

### STM32供电
```
方案1: USB供电 (推荐调试时使用)
方案2: L298N 5V输出 → STM32 5V引脚
```

### 共地
```
电池GND → L298N GND → STM32 GND → 蓝牙GND → OLED GND
(所有模块必须共地！)
```

## L298N连接（4电机方案）

### 模块1：左侧两个电机
| L298N引脚 | 连接 | 说明 |
|-----------|------|------|
| 12V | 电池+ | 电机供电 |
| GND | 电池- | 共地 |
| 5V | STM32 5V | 跳线帽在，输出5V |
| ENA | PA0 (TIM2_CH1) | 左侧速度(PWM) |
| IN1 | PA4 | 左侧方向 |
| IN2 | PA5 | 左侧方向 |
| OUT1 | 左前电机+ | |
| OUT2 | 左前电机- | |
| OUT3 | 左后电机+ | |
| OUT4 | 左后电机- | |

### 模块2：右侧两个电机
| L298N引脚 | 连接 | 说明 |
|-----------|------|------|
| 12V | 电池+ | 电机供电 |
| GND | 电池- | 共地 |
| 5V | 不接 | 跳线帽可拔 |
| ENA | PA1 (TIM2_CH2) | 右侧速度(PWM) |
| IN1 | PA6 | 右侧方向 |
| IN2 | PA7 | 右侧方向 |
| OUT1 | 右前电机- | ⚠️ 注意：接负极 |
| OUT2 | 右前电机+ | ⚠️ 注意：接正极 |
| OUT3 | 右后电机+ | |
| OUT4 | 右后电机- | |

### 右前电机接线特殊说明
由于左右电机安装方向是镜像的，右前电机需要交换接线：
- OUT1 → 右前电机 -（负极）
- OUT2 → 右前电机 +（正极）

这样发送'1'时，所有轮子都会向前转。

### 控制逻辑
```
同侧两个电机并联，同步转动：
- 前进：两侧都正转（右前电机因接线交换，实际方向向前）
- 后退：两侧都反转
- 左转：左侧停 + 右侧正转
- 右转：左侧正转 + 右侧停
```

## 接线顺序（安全原则）

1. ⚡ **先接GND** - 所有模块的GND先连接
2. 🔴 **再接电源** - VCC/VIN最后连接
3. 🟡 **最后接信号** - GPIO、I2C、UART等

## 常见问题

### Q: 电机不转？
- 检查L298N的12V供电
- 检查ENA/ENB是否连接
- 用万用表测量IN1/IN2是否有电平变化

### Q: 蓝牙连不上？
- 检查VCC是否接3.3V（不是5V！）
- 检查TX/RX是否交叉连接
- 确认STM32的PA9/PA10已正确配置

### Q: OLED不显示？
- 检查I2C地址是否为0x3C
- 用I2C扫描程序检测设备地址
- 确认SCL/SDA没有接反

### Q: 蜂鸣器一直响？
- PB0默认应输出高电平（静音）
- 检查蜂鸣器是否为低电平触发
- 确认代码中Buzzer_Init()已调用
