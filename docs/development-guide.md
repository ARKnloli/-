# 蓝牙小车开发指南

## 开发原则

### 1. 稳定优先
- 每次只修改一个功能
- 修改后立即测试验证
- 保持代码可回滚

### 2. 分步实施
- 将大任务拆分为小步骤
- 每步完成后确认正常再继续
- 记录每步的测试结果

### 3. 文档同步
- 代码修改同步更新文档
- 记录问题和解决方案
- 保持开发日志更新

## 代码规范

### 命名规范
- 变量：小写下划线 `current_speed`
- 函数：大驼峰 `Motor_SetSpeed`
- 宏定义：全大写 `MOTOR_PWM_MAX`
- 文件名：小写下划线 `motor_control.c`

### 注释规范
```c
/**
  * @brief  函数功能说明
  * @param  参数说明
  * @retval 返回值说明
  */
```

### 代码结构
```c
/* Includes */
#include "xxx.h"

/* Private defines */
#define XXX  100

/* Private variables */
static uint8_t var;

/* Private functions */
static void Func(void);

/* Exported functions */
void Func_Public(void);
```

## 调试方法

### 1. 最小化测试
- 只保留一个功能
- 逐步排除问题
- 确认每个模块正常

### 2. 可视化调试
- OLED显示调试信息
- LED指示状态
- 串口输出日志

### 3. 声音反馈
- 蜂鸣器确认收到指令
- 不同提示音区分状态

## 版本控制

### Git使用规范
- 每个功能一个分支
- 完成后合并到主分支
- 提交信息清晰明确

### 提交信息格式
```
类型：简短描述

详细说明（可选）

类型：
- feat: 新功能
- fix: 修复bug
- docs: 文档更新
- style: 代码格式
- refactor: 重构
- test: 测试
- chore: 构建/工具
```
