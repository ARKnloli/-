# 执行计划 — 历史粘贴板

## 执行原则

1. **一阶段一步**：每个阶段完成后验证，确认无误再进入下一阶段
2. **每阶段记录日志**：在 `logs/` 下记录完成情况和待办事项
3. **可回退**：每阶段产出独立可运行，出问题只回退当前阶段

---

## 阶段 1：项目初始化

**目标**：能启动一个空白的 Electron 窗口

### 步骤
1. 创建 `package.json`，安装 `electron` 依赖
2. 创建 `main.js`：创建 BrowserWindow，加载空白页
3. 创建 `preload.js`：预留 contextBridge 框架
4. 运行验证：窗口正常打开

### 验证标准
- `npm start` 能启动，出现 Electron 窗口
- 窗口标题为"历史粘贴板"

---

## 阶段 2：数据库层

**目标**：SQLite 数据库正常读写

### 步骤
1. 安装 `better-sqlite3`
2. 创建 `database.js`：建表 + CRUD 函数
3. 在 main.js 中调用初始化，验证表创建成功
4. 手动测试增删查功能

### 验证标准
- 启动应用后在用户数据目录生成 `.db` 文件
- 数据库两表结构正确
- 增删查函数返回正确数据

---

## 阶段 3：系统托盘 + 剪贴板监听

**目标**：托盘常驻，能自动抓取复制内容

### 步骤
1. 准备托盘图标（`assets/icon.png`）
2. 实现托盘：图标 + 右键菜单（打开/退出）
3. 实现剪贴板轮询（文字 + 图片）
4. 新内容写入数据库
5. 关闭窗口隐藏到托盘

### 验证标准
- 托盘图标显示
- 右键菜单正常
- Ctrl+C 复制后数据库有新记录
- 关闭窗口后托盘仍在

---

## 阶段 4：主窗口 UI

**目标**：卡片列表、搜索、操作全部可用

### 步骤
1. 创建 `renderer/index.html`：整体布局
2. 创建 `renderer/style.css`：按设计规范写样式
3. 创建 `renderer/app.js`：
   - 加载并渲染卡片列表
   - 搜索过滤
   - 置顶/取消置顶
   - 删除
   - 点击复制
4. IPC 通道实现（main.js ↔ renderer）

### 验证标准
- 主窗口显示卡片列表，排序正确
- 搜索框输入能过滤
- 置顶/删除按钮功能正常
- 点击卡片能复制到剪贴板

---

## 阶段 5：设置 + 开机自启 + 自动清理

**目标**：完整的设置功能和生命周期管理

### 步骤
1. 设置面板 UI（滑入式侧边栏）
2. 存储期限读写
3. 开机自启配置
4. 自动清理：按天数 + 按容量
5. 清理定时器（30 分钟间隔）

### 验证标准
- 修改存储期限后生效
- 关机重启 → 应用自动启动
- 手动/自动清理正常工作
- 图片超 500MB 自动清理

---

## 阶段 6：打包测试

**目标**：生成可安装的 exe 文件

### 步骤
1. 安装配置 electron-builder
2. 配置 NSIS 安装包参数
3. 生成 exe 安装包
4. 在干净环境安装测试

### 验证标准
- 生成 .exe 安装包
- 安装成功
- 所有功能正常
- 卸载干净无残留

---

## 完成标准

所有 6 个阶段验证通过 → 项目交付。
