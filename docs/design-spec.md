# UI 设计规范 — 历史粘贴板

## 设计原则

- **简洁**：减少视觉噪音，一个操作一个按钮
- **直观**：不需要学习，看图标就懂
- **轻量**：小窗口，不占屏幕空间

## 窗口规格

- 默认尺寸：400 × 600 像素
- 最小尺寸：350 × 450 像素
- 标题：历史粘贴板

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| 页面背景 | `#F0F6FC` | 极淡蓝灰 |
| 卡片背景 | `#FFFFFF` | 白色 |
| 卡片阴影 | `rgba(0,0,0,0.06)` | 轻微投影 |
| 主色调 | `#4A90D9` | 按钮、搜索框聚焦边框 |
| 主色悬浮 | `#3A7BC8` | 按钮 hover |
| 置顶图标色 | `#F5A623` | 已置顶状态 |
| 标题文字 | `#1A1A1A` | 主要文字 |
| 正文文字 | `#333333` | 卡片内容 |
| 辅助文字 | `#999999` | 时间戳、提示 |
| 危险操作 | `#E05555` | 删除按钮 |
| 分割线 | `#EBEBEB` | 卡片间分隔 |

## 字体

- 系统默认中文字体（微软雅黑 / PingFang SC）
- 标题：14px / 加粗
- 正文：13px / 常规
- 辅助文字：12px / 常规
- 等宽数字用于时间

## 布局结构

```
┌──────────────────────────────────────┐
│  🔍 [搜索历史...]          [⚙ 设置] │  ← 工具栏 (高 48px)
├──────────────────────────────────────┤
│                                      │
│  ┌────────────────────────────────┐  │
│  │ ⭐ 这是复制的一段文字内容...  🗑 │  │  ← 卡片 (padding 12px)
│  │                    2 分钟前     │  │     圆角 8px
│  └────────────────────────────────┘  │     卡片间距 8px
│                                      │
│  ┌────────────────────────────────┐  │
│  │ [图片缩略图]               🗑 │  │
│  │                    10 分钟前    │  │
│  └────────────────────────────────┘  │
│                                      │
│            （滚动区域）               │
│                                      │
├──────────────────────────────────────┤
│  共 N 条记录   图片: 120MB / 500MB  │  ← 底部状态栏 (高 32px)
└──────────────────────────────────────┘
```

## 卡片设计

### 文字卡片
- 显示前 30 个字符，超出显示 "..."
- 单行，不换行
- 左侧：置顶图标 ⭐（灰色=未置顶，橙色=已置顶）
- 右侧：删除按钮 🗑
- 底部：相对时间（刚刚 / N 分钟前 / N 小时前 / N 天前）

### 图片卡片
- 缩略图高度 80px，宽度自适应填充
- object-fit: cover 保持比例
- 其他同文字卡片

### 交互状态
- hover：卡片阴影加深
- 点击复制：卡片边框短暂变为蓝色（300ms 动画）
- 置顶卡片：在顶部，有淡橙色左边框标识

## 设置面板

点击 ⚙ 按钮后，从右侧滑入设置面板（宽度 280px）：

```
┌─────────────────────┐
│     设置          ✕ │
├─────────────────────┤
│ 存储期限             │
│  [1天 ▾]            │
│                     │
│ 图片存储空间         │
│ ████░░░░ 120/500MB  │
│                     │
│ 开机自启     [开关] │
│                     │
│ [立即清理过期数据]   │
└─────────────────────┘
```

## 空状态

当没有任何历史记录时，显示：
- 一个简单的图标（📋）
- 提示文字："还没有复制记录"
- 副文字："试试复制一段文字或图片吧"

## 搜索状态

- 输入即搜索，无需按回车
- 无匹配结果时显示："没有找到相关内容"
- 清除搜索框内容 → 恢复完整列表
