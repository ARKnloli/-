# 开发日志

本文件夹存放项目开发日志，按年/月/日记录开发进展。

## 目录结构

```
devlog/
├── 2026/
│   ├── 06-16.md          # 2026年6月16日日志
│   ├── 06-17.md          # 2026年6月17日日志
│   └── ...
├── TEMPLATE.md           # 日志模板
└── README.md             # 本文件
```

## 日志规范

### 文件命名
- 格式: `MM-DD.md`（月-日.md）
- 示例: `06-16.md` 表示6月16日的日志

### 日志内容
每日日志应包含：
1. **已完成事项** - 今日完成的工作
2. **进行中事项** - 正在进行的工作
3. **待办事项** - 计划但未完成的工作
4. **遇到的问题** - 开发中遇到的问题及解决方案
5. **明日计划** - 第二天的工作计划

### 使用模板
复制 `TEMPLATE.md` 创建新日志：
```bash
cp TEMPLATE.md 2026/06-17.md
```

## 自动记录

在开发过程中，Claude会自动：
1. 每完成一个功能模块，更新日志
2. 遇到问题时，记录问题和解决方案
3. 每日工作结束时，总结今日工作和明日计划

## 日志查看

查看最近日志：
```bash
ls -lt devlog/2026/ | head -5
```

查看今日日志：
```bash
cat devlog/2026/$(date +%m-%d).md
```
