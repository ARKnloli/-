## 遇到的问题

### 问题1: VSCode中文乱码
- **现象**: 打开51单片机的C文件，中文注释显示乱码
- **原因**: 文件编码为GB2312，VSCode默认UTF-8
- **解决方案**: 在settings.json中添加C/C++文件编码配置为GB2312

### 问题2: 蜂鸣器初始电平
- **现象**: CubeMX默认生成低电平，蜂鸣器会一直响
- **原因**: 蜂鸣器低电平触发
- **解决方案**: 在代码中初始化时设为高电平（静音）

## 新增模块说明

### 蓝牙通信模块 (bluetooth.c/h)
- HC-05/06串口中断接收
- 状态机协议解析：帧头(0xAA 0x55) + 命令 + 参数 + 校验
- 支持命令：前进/后退/左转/右转/停止/速度设置/蜂鸣器控制
- 命令回调机制，方便集成

### OLED显示模块 (oled.c/h)
- SSD1306 128x64 I2C驱动
- 支持8x16和6x8两种字体
- ASCII字库完整（空格~波浪号）
- 显示功能：字符、字符串、数字、进度条、像素点
- 开机画面显示

### 主程序功能
- 蓝牙遥控小车（手机APP发送指令）
- OLED实时显示方向和速度
- 蜂鸣器操作提示

## 备注

硬件配置：
- 主控: STM32F103C8T6 (Blue Pill)
- 电机驱动: 2个L298N
- 电源: 4节干电池（约6V）
- 蓝牙: HC-05/06
- 显示: 0.96寸OLED (I2C)
- 蜂鸣器: 低电平触发

通信协议格式：
```
帧头1(0xAA) + 帧头2(0x55) + 命令(1B) + 参数(1B) + 校验(1B)
校验 = 帧头1 XOR 帧头2 XOR 命令 XOR 参数
```
