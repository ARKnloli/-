## 蓝牙通信调试记录

### 问题：接收计数一直是0
- **现象**：手机APP发送成功，但OLED显示RX: 0 0
- **原因**：蓝牙TX/RX接线接反
- **解决**：交换PA9和PA10的接线
- **结果**：✅ 蓝牙通信正常

### 正确接线
```
STM32 PA9(TX)  → JDY-31 RXD（之前错误接到了TXD）
STM32 PA10(RX) ← JDY-31 TXD（之前错误接到了RXD）
```

### 调试信息（OLED显示格式）
```
第0行：Smart Car
第2行：Dir: STOP/FWD/BACK/LEFT/RIGHT
第4行：SPD: 50%
第6行：RX: [接收计数] [原始字节]
第7行：Dir: [方向]
```

## 电机控制代码修改

### 新增4电机独立控制函数
- `Motor_FrontLeftForward(uint16_t speed)` - 左前电机前进
- `Motor_FrontLeftBackward(uint16_t speed)` - 左前电机后退
- `Motor_RearLeftForward(uint16_t speed)` - 左后电机前进
- `Motor_RearLeftBackward(uint16_t speed)` - 左后电机后退
- `Motor_FrontRightForward(uint16_t speed)` - 右前电机前进
- `Motor_FrontRightBackward(uint16_t speed)` - 右前电机后退
- `Motor_RearRightForward(uint16_t speed)` - 右后电机前进
- `Motor_RearRightBackward(uint16_t speed)` - 右后电机后退

### 控制逻辑
- 模块1（左侧）：PA0(ENA), PA4(IN1), PA5(IN2) → 控制左前+左后电机
- 模块2（右侧）：PA1(ENA), PA6(IN1), PA7(IN2) → 控制右前+右后电机
- 同侧两个电机并联，同步转动

### 接线调整记录
- **问题**：右前电机方向与其他轮子相反
- **原因**：左右电机安装方向是镜像的
- **解决方案**：交换右前电机的接线（OUT1接负极，OUT2接正极）
- **状态**：✅ 已解决

### 电机接线最终方案
```
模块1（左侧）：
  OUT1/OUT2 → 左前电机（正常接线）
  OUT3/OUT4 → 左后电机（正常接线）

模块2（右侧）：
  OUT1/OUT2 → 右前电机（交换接线：OUT1→负极，OUT2→正极）
  OUT3/OUT4 → 右后电机（正常接线）
```
